# Как сделан анимированный фон (поле частиц)

Памятка, чтобы повторить эффект в другом проекте. Рабочий код - в `index.html`, второй `<script type="module">`.

## Идея в трёх строках

1. Тысячи частиц рисуются **одним вызовом отрисовки** (инстансинг), а не тысячами отдельных объектов.
2. Вся анимация считается **в шейдере на видеокарте**. JavaScript на каждом кадре только передаёт пару чисел (время, прокрутку, мышь).
3. Частица - это плоский спрайт (картинка, повёрнутая к камере), а не 3D-модель.

Первая версия была из 2600 настоящих 3D-моделей с пересчётом каждой в JS на каждом кадре - она лагала. Текущая держит 9000 частиц при 0,2-0,5 мс работы JS на кадр.

## Из чего состоит

| Часть | Как сделана |
|---|---|
| Библиотеки | three.js 0.160 (WebGL), Lenis 1.1 (плавная прокрутка), обе с CDN |
| Спрайты | Рисуются один раз при загрузке на обычном `<canvas>` 2D (объект `SHAPES`), превращаются в текстуру-атлас 1024x512 с двумя вариантами формы |
| Геометрия | Одна «заготовка растения»: стебель, 2 листа, головка. Размножается через `InstancedBufferGeometry`; у каждого экземпляра свои позиция, размер, фаза, оттенок |
| Вершинный шейдер | Считает рельеф (волны + приподнятые края), полёт вперёд с зацикливанием, покачивание, вращение, поворот спрайта к камере, туман |
| Фрагментный шейдер | Красит стебель и лист формулой, головку берёт из атласа, смешивает с цветом неба по туману и затемнению |
| Края без «лесенки» | `alphaToCoverage` + запись глубины: не нужно сортировать прозрачные частицы |
| Небо | Полноэкранный прямоугольник с градиентом-свечением + 600 точек (`THREE.Points`) с мерцанием. Итого 3 вызова отрисовки на кадр |
| Прокрутка | Lenis двигает страницу; прогресс прокрутки опускает камеру под поле (оно уходит вверх) и затемняет фон |

## Правила, которые дают плавность

- Один цикл `requestAnimationFrame` на всё (прокрутка + фон). Обработчики `scroll`, `pointermove`, `resize` только записывают целевые значения.
- На каждом кадре ничего не создаётся: ни объектов, ни массивов. Меняются только uniform-переменные.
- Ограничен pixel ratio (не больше 1,5): на 4K-экране это в разы меньше пикселей.
- Никаких `backdrop-filter: blur` поверх анимации: размытие пересчитывается каждый кадр.
- Затемнение фона делается в шейдере, а не через `opacity` у canvas.
- Скрытая вкладка останавливает цикл. Без WebGL включается статичный градиент.
- На тач-экранах прокрутка родная, частиц меньше.
- Если браузер рисует без видеокарты (SwiftShader), сразу берётся лёгкий режим.

## Важно при проверке

В Chrome должно быть включено **аппаратное ускорение** (Настройки → Система → «Использовать графическое ускорение»). Без него любой WebGL рисуется процессором и лагает даже с мощной видеокартой. Проверить: `chrome://gpu`.

Ещё одна ловушка: если в Windows выключены «Эффекты анимации» (Параметры → Специальные возможности → Визуальные эффекты), браузер сообщает сайтам `prefers-reduced-motion: reduce`. Сайт, который это учитывает, отключит плавную прокрутку и появление текста. Здесь это управляется флагом `respectReducedMotion`.

## Настройки

Всё вынесено в объект `BG` в начале скрипта: плотность, размер, покачивание, волны, скорость полёта, уход вверх при прокрутке, затемнение, свечение, мини-частицы в небе, качество.

Форма частиц сейчас одна - искры (`SHAPES.sparkle`). Остальные 14 вариантов (цветы, сакура, снежинки и т. д.) лежат в `versions/v3-все-формы.html`: оттуда можно скопировать нужную функцию `draw`.

Диагностика в консоли браузера: `__bg.stats()` - FPS, время JS на кадр, число частиц, видеокарта, число вызовов отрисовки.

## Готовый запрос для нового проекта

> Сделай анимированный фон: поле из N тысяч частиц-спрайтов в перспективе. Один WebGL canvas, инстансинг (`InstancedBufferGeometry`), один вызов отрисовки. Спрайты нарисуй на 2D-canvas в атлас. Рельеф, полёт вперёд с зацикливанием, покачивание и поворот к камере считай в вершинном шейдере; в JS на кадр только uniform-переменные. `alphaToCoverage` вместо сортировки прозрачности. Один цикл requestAnimationFrame вместе с плавной прокруткой Lenis. Прогресс прокрутки двигает камеру и затемняет фон в шейдере. Ограничь pixel ratio до 1,5, без backdrop-filter поверх canvas, пауза в скрытой вкладке, статичный фон без WebGL, меньше частиц на телефоне. Вынеси настройки в один объект.
